# IMF Financial Sector Assessment Program (FSAP) reports — GCC countries

FSSA = Financial System Stability Assessment (main findings, stress tests, recommendations). DAR = Detailed Assessment Report on one standard: BCP = Basel Core Principles (banking supervision), IOSCO = securities regulation, FMI = payment systems / market infrastructures, AML = anti-money laundering and combating the financing of terrorism.
